# Anki 단어 수집기

## 실행

1. Windows용 Python 3.10 이상을 설치합니다. 일반 Python 설치 프로그램의 Tcl/Tk 옵션을 포함하세요.
2. `anki_word_collector.py`를 쓰기 가능한 폴더에 저장합니다.
3. 그 폴더에서 터미널을 열고 실행합니다.

```powershell
py anki_word_collector.py
```

`py` 명령이 없으면 `python anki_word_collector.py`로 실행합니다.
추가 패키지 설치는 없습니다. requirements.txt는 안내용입니다.
tkinter 설치 확인은 `py -m tkinter`로 할 수 있습니다.

## 사용

- 단어 또는 표현 입력 후 Enter: MyMemory에서 한국어 뜻을 조회하고 즉시 TSV에 자동 저장합니다. 입력 언어는 자동 감지 또는 영어·일본어·중국어·스페인어·프랑스어·독일어·러시아어·아랍어·힌디어 중에서 선택할 수 있습니다.
- 자동 감지는 일본어·중국어·러시아어·아랍어·힌디어처럼 문자 체계가 뚜렷한 언어를 인식합니다. 영어·스페인어·프랑스어·독일어처럼 같은 알파벳을 쓰는 언어는 정확도를 위해 목록에서 직접 선택하세요.
- 영어 표현은 전체 자연스러운 해석을 먼저 보여준 뒤, 학습하기 좋게 구성 단위도 나눠 표시합니다. 예: `plenty to go around` → `전체: 모두에게 돌아갈 만큼 충분한 양 | 표현 나누기: plenty = 많은 양, 충분함; to go around = 모두에게 돌아가다, 나눠 줄 만큼 있다`.
- 자동 저장 뒤에도 결과는 화면에 남아 있습니다. 다음 영어를 바로 입력하면 기존 입력이 교체되어 다음 조회를 시작합니다. 뜻을 직접 작성한 경우만 Enter로 저장합니다.
- 뜻 입력란에서 Shift+Enter: 줄바꿈. 저장 시 탭·줄바꿈은 공백으로 합쳐 한 카드가 한 줄에 저장됩니다.
- 인터넷 연결이 없거나 조회에 실패하면 뜻을 직접 입력하고 저장하세요. 자동 조회 없이 뜻 입력란을 클릭해 바로 작성해도 됩니다.
- 항상 위: 다른 창 위에 표시합니다. 설정은 현재 실행 중에만 적용됩니다.
- 목록에서 단어 두 번 클릭: 기존 단어를 불러와 수정합니다.
- 중복은 대소문자와 양끝 공백을 무시하여 확인합니다. 자동 조회한 단어가 이미 있으면 기존 뜻을 안전하게 유지합니다. 수동 저장에서는 기존 뜻과 새 뜻을 보여주고 덮어쓰기를 확인합니다. 취소하면 기존 값과 현재 입력을 유지합니다.
- 덮어쓸 때 영어의 기존 표기를 유지해 Anki 재가져오기 시 앞면이 달라지는 일을 줄입니다.

## 파일과 보존

스크립트와 같은 폴더의 `anki_words.tsv`에 UTF-8, 헤더 없는 두 열로 저장합니다.
첫 저장 때 파일을 만들며 재실행하면 기존 파일을 읽어 목록과 개수를 복원합니다.

```text
apple	사과
abandon	버리다, 포기하다
```

위 예의 두 열 사이는 실제 탭입니다. 별도의 Anki 연결이나 AnkiConnect는 필요 없습니다.
저장은 임시 파일을 완성한 뒤 교체하여 저장 실패 시 기존 파일 손상 위험을 줄입니다.
잘못된 TSV나 중복 행이 이미 있으면 원본을 덮어쓰지 않고 오류를 알립니다.
Windows에서는 같은 폴더의 앱을 두 개 실행할 수 없습니다. `anki_words.lock`은 잠금용 보조 파일이며 Anki에 가져오지 않습니다.
실행 중 TSV를 다른 편집기로 수정하면 저장을 중단합니다. 현재 입력을 복사한 뒤 앱을 다시 실행하세요.
별도 백업 파일을 생성하지는 않으므로 중요한 단어 파일은 정기적으로 복사해 보관하세요.

## 번역 서비스

MyMemory의 공개 GET API를 `en|ko`로 사용합니다. API 키·가입·유료 결제·외부 Python 패키지가 필요 없습니다.
입력한 영어와 접속 IP가 서비스에 전달됩니다. 수동으로 작성한 한국어 뜻은 로컬 TSV에만 저장합니다.
무료 사용량 제한, 서버 상태에 따라 자동 조회가 실패할 수 있습니다. 요청당 최대 500바이트이며 앱은 약 15초 후 기다리기를 끝냅니다.
일반 번역 결과이므로 품사와 여러 사전 뜻이 항상 나오지는 않습니다. `plenty to go around`처럼 앱에 등록된 표현은 문맥에 맞는 학습 해설을 먼저 사용합니다. 그 밖의 표현은 `to go around` 같은 `to + 동사 + 전치사/부사` 묶음을 우선 보존하고, 나머지는 낱말 단위로 나눕니다. 복잡한 관용 표현은 문맥에 맞게 확인·수정하세요.

- API 문서: https://mymemory.translated.net/doc/spec.php
- 서비스 사용량 제한: https://mymemory.translated.net/doc/usagelimits.php

## Anki로 가져오기

1. Anki에서 파일 → 가져오기로 `anki_words.tsv`를 선택합니다.
2. 구분자를 탭으로 설정합니다.
3. 노트 유형은 기본/Basic, 원하는 덱을 선택합니다.
4. 1열은 앞면/Front, 2열은 뒷면/Back으로 연결합니다.
5. HTML 허용 옵션은 끄고 미리보기에서 영어와 한국어가 올바르게 나오는지 확인합니다.
6. 다시 가져올 때는 기존 노트 업데이트 설정을 확인하세요. 앱의 중복 검사와 Anki의 가져오기 중복 처리는 별개입니다.

Anki 공식 안내: https://docs.ankiweb.net/importing/text-files.html
